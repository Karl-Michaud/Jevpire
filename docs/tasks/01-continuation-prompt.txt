## What this project is

Jevpire evaluates whether Jev — TypeSafe AI's "System One" decision model, released 2026-09-15 — can call baseball balls and strikes. Jev is NOT an LLM: it takes a JSON/text state block plus typed questions and returns typed values with calibrated probabilities and confidence, no generated text. Its three headline claims are accuracy, calibration (trained via "RLCD"), and 70–500 ms latency. A pitch is in flight for 390–450 ms, so all three are testable at once.

Read docs/PLAN.md first — it is the single source of truth and everything derives from it. Then docs/PLAN_REDTEAM.md (four red-team rounds, converged), docs/DATA_DICTIONARY.md (the 2026 data, verified against live APIs), and docs/LOG.md.

## Non-negotiable gotchas (each one already cost a bug)

- NEVER read plate_x/plate_z/pX/pZ directly. Re-derive location from the nine trajectory parameters at an explicitly named plane. StatsAPI is front-of-plate, Savant is middle-of-plate; they differ by up to 1.2 inches.
- Trajectory coefficients are anchored at y=50 ft, NOT the release point. Release is at negative t. Savant gives the release point, so use PitchTrajectory.from_release_anchored.
- details.call.code on a challenged pitch is the POST-challenge corrected call. The umpire's original must be flipped when isOverturned. Getting this backwards gives ~58% agreement — a coin flip.
- StatsAPI omits no_pitch events (pitch-timer violations) from pitch_number; Savant counts them. Join on PitchRecord.savant_pitch_number.
- Ground truth: strike iff at y=0.70833 ft, |x| <= 0.70833+0.12083 AND sz_bot-0.12083 <= z <= sz_top+0.12083. The ball radius on all four edges is load-bearing — dropping it takes agreement from 100% to 61%.
- The 2026 season is still in progress. Filter on status.detailedState == "Final" and re-enumerate; never hardcode a game count.
- Exclude automatic_ball (pitch-clock violations — nobody judged anything) and hit_by_pitch. Include blocked_ball.
- Be polite to MLB: keep the 0.15s throttle in CachedFetcher, cache aggressively, never re-fetch on a re-run.
